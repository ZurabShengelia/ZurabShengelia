## `01` / About Me

Hi, I'm **Zurab Shengelia**, a Computer Science student interested in full-stack development and cybersecurity.

My programming journey started at **14**, when I wrote my first lines of code using Brackets. Gaming sparked my curiosity about technology, and that curiosity gradually grew into an interest in building software and understanding what happens behind the scenes.

Today, I enjoy developing web applications, exploring Linux, learning networking fundamentals, and studying web application security and secure coding.

I'm still learning, experimenting, and improving with every project.

## `04` / Cybersecurity

I'm actively learning cybersecurity with an emphasis on understanding how applications and systems work, where they can fail, and how to make them safer.

- **Web application security:** Understanding common vulnerabilities and how to prevent them.
- **Ethical hacking:** Learning security assessment techniques in authorized environments.
- **Network security:** Studying network protocols, traffic analysis, and service discovery.
- **Linux security:** Exploring permissions, system configuration, processes, and access control.
- **Authentication & secure coding:** Learning safer ways to handle sessions, tokens, input validation, and authorization.
- **Security tools:** Practicing with tools such as Nmap and Wireshark while developing a stronger foundation in vulnerability analysis.

My approach is to learn the fundamentals first, practice in controlled labs, and understand both how vulnerabilities work and how to fix them.

## `06` / How I Build

I believe the best way to learn programming is to build something, encounter a problem, understand why it happens, and work through a solution.

My usual approach:

- **Learn** the underlying concepts instead of relying only on ready-made solutions.
- **Build** practical projects that connect theory with real implementation.
- **Explore** the tools, systems, and technologies behind the code.
- **Improve** through debugging, testing, refactoring, and learning from mistakes.

I'm especially interested in the intersection of software development, Linux, and security: writing applications is one thing, but understanding how to build them responsibly is just as important.
